# AI Interview Coach

A full-stack interview practice app powered by a locally installed Ollama model. It generates role-aware questions, evaluates each answer against question-specific concepts, and produces a detailed performance report.

## Features
- Responsive interview studio UI
- Role, experience, interview type, and difficulty setup
- One-question-at-a-time interview flow
- Local Ollama-powered questions and answer evaluations
- Six evaluation dimensions, missing/correct concepts, and improved sample answers
- Browser microphone input using the Web Speech API when available
- Downloadable PDF performance report
- Local history tracking in the browser

## Stack
- Frontend: React + Vite
- Backend: Python + Flask
- Local AI: Ollama (default model `qwen2.5:3b`)

## Quick start (Windows)

### Option 1: Double-click the launcher
From the project root, run:

```bat
START_APP.bat
```

Before starting, make sure Ollama is running and `qwen2.5:3b` is installed. The launcher will:
- create the backend virtual environment if needed
- install Python requirements
- create a local `.env` file from `.env.example` if missing
- check whether the Ollama server is reachable
- start the Flask backend at http://127.0.0.1:5000
- start the Vite frontend at http://127.0.0.1:5173
- open the app in the default browser

### Option 2: Manual startup
```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python app.py
```

Then in a second terminal:

```powershell
cd frontend
npm install
npm run dev -- --host 127.0.0.1
```

Open the frontend at http://127.0.0.1:5173.

## Ollama configuration
The defaults in `backend/.env.example` are:

```env
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen2.5:3b
OLLAMA_TIMEOUT_SECONDS=120
PORT=5000
```

To prepare Ollama on Windows, run `ollama serve` if it is not already running and `ollama pull qwen2.5:3b` if the configured model is not installed. Confirm the model with `ollama list`. The app checks `/api/tags` and shows whether Ollama is reachable and the configured model is installed. It does not silently substitute canned questions or scores when Ollama is unavailable.

Question generation, evaluations, and final summaries use bounded JSON-schema output supported by Ollama. Evaluation fields and score ranges are validated by Flask, and the overall score is calculated from the six dimension scores. Invalid or truncated model responses receive one bounded retry; next-question generation asks for distinct alternatives to avoid repeating an earlier question.

## Notes
- Keep your machine's `.env` local; it is ignored by Git.
- Speech recognition depends on browser support and microphone permissions; typing remains available when it is unsupported.
- The project uses React JSX (not TypeScript) with Vite and a Flask backend.
- Downloaded reports are generated by the Flask backend as formatted PDF files.
